At a glance

Actions

Load starter scores

Fills all three boards with ten times apiece so the first visitor of the day has something to beat. The scores are deliberately soft — one good time at the top, easy going after that. Loading again replaces the previous set rather than stacking another one on top.

Reset everything

Deletes every score on every board, starter and real alike. This cannot be undone.

Entries

The top ten and the most recent runs on each board — everything currently visible on the display. Remove anything the word filter missed.

Delete every score?

This removes all 0 entries from every board, starter scores and real ones alike. It cannot be undone.
